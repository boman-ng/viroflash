Measurement definitions

This report measures profile-attributed fragment fractions, not viral load or clinical positive/negative status. Reference descriptions come from the indexed FASTA. Exact-equivalent members within a group cannot be distinguished.

Intervals use simultaneous equal-tailed exact hypergeometric inversion with 95% familywise coverage across the complete fixed target family. They describe candidate sampling uncertainty only and do not correct for signals missed by the prescreen or attribution. Split and discordant fragment counts are not confirmed integration event counts.

Methods and limitations

All input fragments undergo a target 21-mer Bloom prescreen during one validated FASTQ pass. Retained candidates are sampled using deterministic BLAKE3 Bernoulli selection and undergo competitive HOST+TARGET minimap2 alignment. Candidate-population interval endpoints are divided by the original input count to obtain library abundance. References outside the index remain unmodeled. Cross-group ambiguity, host conflict, and unevaluable fragments are retained in the full evidence.
