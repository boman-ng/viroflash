Library abundance estimates detectable support as a percentage of all original input fragments, with a simultaneous 95% sampling interval. Target score is (estimated fraction − target fraction) / (estimated fraction + target fraction): negative below the selected ppm target, zero at the target, positive above it. It describes relative abundance, not confidence.

Coverage is the fraction of reference bases covered. One fragment is one SE read or one PE pair. Each group contains identical or reverse-complement reference sequences.

Analysis method

{{METHOD}} Both modes read FASTQ once and keep the sample in memory. The same precision-derived capacity applies to the input population in screen mode and the candidate population in full mode.

Abundance intervals use exact hypergeometric inversion and cover sampling uncertainty under the uniform hash-priority model. Percentages use the original input denominator. Split and discordant counts describe alignment patterns.
